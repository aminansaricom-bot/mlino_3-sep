# MLINO V2 Changelog

## ۲۰۲۶-۰۹-۱۱ — بنیاد جریان Intent

- چرخه هفت‌حالته، revision و تأیید دقیق همان نسخه در Core؛ اصلاح/رد، انقضا و پاک‌سازی نشست.
- رابط مرور و تأیید بیان صریح کاربر روی Assistant موجود؛ بدون parser/LLM، Matching، داده کسب‌وکار یا persistence جدید.
- ۴۱ تست جدید؛ مجموع ۲۰۱ تست موفق، TypeScript و build موفق. Chrome روی build واقعی در اندازه‌های ۳۹۰×۸۴۴ و ۱۲۸۰×۹۰۰: عدم ارسال Intent، عدم تغییر ذخیره‌سازی، اصلاح/تأیید و پاک‌سازی موفق.
- یک تست قدیمی آفر پیش از تغییرات به‌علت انقضای fixture شکست داشت؛ ساعت فقط همان تست ثابت شد. کد Matching یا داده‌های آزمایشی تغییر نکردند.
- مبنای ثبت‌نشده Assistant استرا با چک‌سام در کامیت مستقل حفظ شد؛ پوشه کاری استرا و main دست‌نخورده‌اند. تست گوشی واقعی انجام نشده است.
