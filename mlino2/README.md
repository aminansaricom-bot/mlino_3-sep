# mlino2/ — پوشه‌ی توسعه‌ی MLINO V2

این پوشه محل کار **موجی** (GLM 5.3 Flash) روی MLINO V2 است — سمت مشتری MLINO، لایه‌ی هوشمند اتصال کسب‌وکارها و مشتری‌ها. این پوشه **مستقل و موازی** با `implementation/` (که V1 است) توسعه پیدا می‌کند.

## ترتیب خواندن (برای موجی)

1. **`00_PRODUCT_VISION.md`** — چشم‌انداز کامل محصول V2، دقیقاً از زبان مالک محصول.
2. **`01_ARCHITECTURE_PRINCIPLES.md`** — قواعد مهندسی الزامی، مخصوصاً مرز V1/V2.
3. **`02_V1_V2_INTEGRATION_CONTRACT_DRAFT.md`** — شکل داده‌ای که باید از همین امروز رعایت شود تا آینده قابل‌ادغام بماند.
4. **`03_ROADMAP_PHASES.md`** — فازبندی پیشنهادی کار.
5. **`HANDOFF/`** — اینجا هر تحویل/گزارش کار موجی ثبت می‌شود (مشابه `AI_HANDOFF/` در V1، اما مستقل — این دو پروژه‌ی موازی جدا از هم گزارش می‌دهند).

## قانون طلایی

V2 هرگز مستقیماً به کد/دیتابیس/معماری V1 (پوشه‌ی `implementation/` و `ARCHITECTURE_BASELINES/` در ریشه‌ی همین Repository) دست نمی‌زند و تغییرشان نمی‌دهد. اگر برای انجام کاری نیاز به تغییر چیزی در V1 داری، آن را در `HANDOFF/` به‌عنوان یک درخواست مستند کن — تصمیم نهایی با یونس/مالک محصول است.
