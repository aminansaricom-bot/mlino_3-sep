# G3b — اعتبارسنجی اصلاحات CCR شِمای Core

این پوشه شواهد مستقل G3b را نگه می‌دارد. هیچ artifact از `g3` تغییر نکرده و هیچ فایل این پوشه شِما یا migration محصول نیست.

دامنه‌ی اعتبارسنجی:

- اصلاحات R-1 تا R-7
- تصمیم مالک `D6=A`
- C1 تا C15
- آزمون‌های T1 تا T12
- W1 از مسیر Prisma
- بازپخش پنج migration در `origin/main`
- بقای اشیای دستی پس از migration نامرتبط
- عدم تغییر نصب Prisma موجود

محیط:

- PostgreSQL `16.15` در container دارای `--rm` و `tmpfs`، بدون volume
- Prisma CLI و Client دقیقاً `5.22.0`
- Client تولیدی فقط در پوشه‌ی موقت بیرون مخزن

نتیجه‌ی تفصیلی در `VALIDATION_RESULTS.md` و خروجی کامل در `logs/` ثبت شده است.

من کدکس هستم.
