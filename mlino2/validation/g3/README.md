# G3 — اعتبارسنجی پیش‌نویس CCR شِمای Core

این پوشه شواهد بازتولیدپذیر اعتبارسنجی متن دقیق Prisma و SQL مندرج در
`CONTRACT_CHANGE_REQUEST_CORE_FOUNDATION_SCHEMA.md` را نگه می‌دارد. هیچ فایل تولیدی این پوشه migration یا شِمای production نیست.

## محیط

- PostgreSQL: `16.15`
- Prisma CLI و Client: دقیقاً `5.22.0`
- Node.js: `24.18.0`
- پایگاه داده: کانتینر `--rm` با `tmpfs` و بدون volume
- Client تولیدی: فقط در پوشه‌ی موقت بیرون مخزن

## نتیجه

- متن موقت Prisma معتبر است و Client تولید می‌شود.
- خروجی `migrate diff --from-migrations` با SQL ثبت‌شده بایت‌به‌بایت یکسان است.
- پنج migration موجود، SQL تولیدی Core و SQL دستی C1 تا C15 از صفر بازپخش شدند.
- C1 تا C15 با SQLSTATE دقیق مورد انتظار عبور کردند.
- نوشتن scalar مستقیم بین دو سازمان از مسیر Prisma با `P2003` رد شد.
- آزمون هم‌زمانی انتشار یک برنده و یک بازنده با `23505` داشت.
- یک migration نامرتبط فقط یک ستون افزود و inventory قیود، ایندکس‌ها و Triggerها را تغییر نداد.
- همه‌ی FKهای ۱۲ مدل Core جدید `ON DELETE RESTRICT` و `ON UPDATE RESTRICT` هستند.

## یافته و اصلاح داخل پیش‌نویس

اجرای نخست C6 نشان داد که عبارت سه‌مقداری SQL می‌تواند `NULL` را در `CHECK` عبور دهد. متن دقیق C6 در پیش‌نویس اصلاح شد تا هر دو جزء رابطه‌ی مرکب صریحاً هم‌زمان مقدار داشته باشند. پس از بازسازی کامل محیط، آزمون C6 با `23514` عبور کرد. این اصلاح تصمیم معماری را تغییر نمی‌دهد.

## ساختار شواهد

- `prisma/`: متن استخراج‌شده‌ی Prisma و SQL دستی، عیناً از CCR
- `sql/`: migration تولیدی و آزمون‌های SQL
- `scripts/`: استخراج، ساخت شِمای موقت، hash و آزمون Prisma
- `logs/`: خروجی‌های بدون credential
- `SHA256SUMS.txt`: hash بایت‌های ذخیره‌شده‌ی همه‌ی artifactها، به‌جز خود manifest
