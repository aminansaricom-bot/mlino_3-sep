# شواهد اعتبارسنجی G4 شِمای Core Foundation

این پوشه شواهد اجرای دستور `CODEX-20260913-G4-CORE-SCHEMA-MIGRATION-001` را نگه می‌دارد.

- PostgreSQL 16 در container یک‌بارمصرف با `tmpfs` اجرا شد و هیچ volumeای نداشت.
- هر شش migration، از دیتابیس خالی و به ترتیب، با موفقیت اعمال شدند.
- Prisma 5.22.0 از نصب `_PUSH_STAGING` فقط به‌صورت خواندنی استفاده شد.
- Client آزمایشی فقط در پوشهٔ موقت `g4-tooling` تولید و پس از آزمون حذف شد.
- اتصال و credential موقت در هیچ artifact ثبت نشده است.
- شواهد G3 و G3b تغییر نکرده‌اند.

نتیجهٔ تفصیلی در `VALIDATION_RESULTS.md` و خروجی خام هر مرحله در `logs/` ثبت شده است.
