# ثبت شکست مرحلهٔ Backup در G7

## رخداد

فرمان ایجاد `C:\Users\galexy\mlino-backups` از `New-Item -LiteralPath` استفاده کرد، اما نسخهٔ PowerShell فعال این پارامتر را برای فراخوانی انجام‌شده نپذیرفت. چون پوشه ساخته نشد، `Start-Process` نتوانست مسیر خروجی `pg_dump` را باز کند و خود فرایند backup آغاز نشد.

همچنین قالب‌بندی timestamp بدون `InvariantCulture` تحت فرهنگ فارسی مقدار شمسی `14050622T120945Z` تولید کرد. این مقدار در هیچ فایل ساخته‌شده‌ای ثبت نشد، زیرا پوشهٔ مقصد وجود نداشت.

## اثر

- فایل backup: ساخته نشد.
- تغییر دیتابیس: صفر.
- migration جدید: اعمال نشد.
- restart container: صفر.
- اجرای مجدد backup: انجام نشد، مطابق hard stop دستور.

## اصلاح لازم برای دستور بعدی

- ساخت پوشه با `New-Item -Path ... -ItemType Directory -Force`.
- تولید timestamp با `CultureInfo.InvariantCulture` یا قالب مستقل از فرهنگ.
- سپس اجرای backup از ابتدا و بررسی خوانایی پیش از هر migration.

این موارد پیشنهاد اجرایی برای دستور بعدی‌اند و در این اجرا اعمال نشدند.
