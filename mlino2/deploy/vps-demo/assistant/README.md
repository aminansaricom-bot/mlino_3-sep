# دروازه‌ی دستیار V2 روی VPS نمایشی

**وضعیت:** آماده، ولی نصب نشده.

## پیش‌نیازها

روشن شدن دروازه دو پیش‌نیاز دارد:

1. **تصمیم مالک درباره‌ی U-G1.** دستیار متن جست‌وجو را به CodeCraft می‌فرستد و مدت نگه‌داری داده نزد CodeCraft نامعلوم است. تا تأیید مالک، Caddy مسیر `/assistant/*` را با 404 می‌بندد.
2. **کلید CodeCraft روی سرور.** مالک خودش کلید را می‌گذارد:
   ```
   nano /etc/mlino/assistant-keys.txt      # هر کلید در یک خط، با cc_ شروع می‌شود
   chmod 600 /etc/mlino/assistant-keys.txt
   ```
   **کلید هرگز در مخزن، لاگ یا مرورگر نیست.** سرویس آن را فقط به‌صورت credential فقط‌خواندنی می‌گیرد (`LoadCredential`)، با کاربر موقت و بی دسترسی نوشتن.

## نصب

1. فایل‌های `app/gateway/server.mjs` و `app/gateway/assistantCore.mjs` را به `/tmp/mlino-assistant/` روی سرور کپی کن.
2. `install-assistant.sh` را با root اجرا کن. این اسکریپت:
   - سرویس را نصب می‌کند؛
   - سلامت دروازه را می‌سنجد؛
   - در Caddy فقط بلوک `/assistant/*` سایت explore را به `127.0.0.1:8787` می‌برد (نسخه‌ی پشتیبان هم نگه می‌دارد)؛
   - سپس Caddy را اعتبارسنجی و بارگذاری دوباره می‌کند.
3. V2 را با `VITE_ASSISTANT_REMOTE=1` بساز و مستقر کن.

## برگرداندن

```
systemctl disable --now mlino-assistant
```

سپس نسخه‌ی پشتیبان Caddyfile را برگردان و `systemctl reload caddy` را اجرا کن.

- ۲ درخواست هم‌زمان؛
- سقف روزانه‌ی ۲۰۰۰ درخواست؛
- مهلت ۹ ثانیه.
