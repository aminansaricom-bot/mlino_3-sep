## پیش از شروع کار روی این بسته بخوان

1. **قانون طلایی مرزها:** این پروژه هم‌زمان چند نفر روی خود دارد — `mlino2/` قلمرو اجرایی موجی است، بازبینی مستقل با ممد، و V1 با یونس. تغییرات این پاس با مجوز مستقیم مالک محصول و گزارش بازبینی کلاد ثبت شده‌اند.
2. **فایل‌های منجمد:** `implementation/shared-contracts/types.ts` و `implementation/prisma/schema.prisma` بدون CCR مصوب **صفر تغییر**.
3. **قرارداد `02`** (`mlino2/02_V1_V2_INTEGRATION_CONTRACT_DRAFT.md`) بدون CR تغییر نمی‌کند. یک CR باز روی همین موضوع هست: `mlino2/HANDOFF/20260908_CR_AR_UI_CONTRACT_GAPS.md`.
4. **اصل صداقت داده:** هیچ فیلد یا قابلیت ساختگی به‌عنوان داده‌ی واقعی نمایش داده نمی‌شود. چیزی که در قرارداد نیست، ساخته نمی‌شود — حتی خالی.
5. **پروتکل تحویل:** هر تحویل با گزارش در پوشه‌ی HANDOFF مربوطه + چک‌سام فایل‌ها + Push، سپس بازبینی مستقل.

## نکته‌ی نگهداری

این یک Snapshot است، نه منبع حقیقت. **منبع حقیقت خودِ ریپو است.** اگر نسخه‌ی جدیدی لازم شد، فایل قبلی **جایگزین** شود نه اینکه کنارش انباشته شود — وگرنه هر Snapshot داخل Snapshot بعدی می‌رود و حجم ریپو بی‌دلیل بالا می‌رود.

اگر استرا به Git دسترسی دارد، `git clone` مستقیم بهتر از این بسته است: تاریخچه و Branchها را هم می‌گیرد.
