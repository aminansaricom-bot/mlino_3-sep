# الگوی adapter کلید خروجی عمومی

این پوشه فقط کد و الگو دارد؛ **هیچ کلید یا descriptor واقعی نباید در مخزن قرار گیرد.** فایل descriptor و کپیِ `adapter-shim.template.cjs` باید بیرون مخزن باشند. اپراتور، مسیر مطلق ماژول ساخته‌شده را در کپی shim جایگزین می‌کند و `MLINO_EXPORT_KEY_PROVIDER_MODULE` را به مسیر مطلق همان shim و `MLINO_EXPORT_KEYSTORE_PATH` را به مسیر مطلق descriptor اشاره می‌دهد. فایل الگو به‌تنهایی اجراشدنی نیست.

فقط حساب producer باید بتواند descriptor را بخواند و DPAPI از نوع `CurrentUser` به همان حساب وابسته است. ابزار ساخت کلید و زمان‌بند باید زیر **همان حساب با پروفایل کاربری بارگذاری‌شده** اجرا شوند؛ کپی کلید محافظت‌شده به حساب دیگری برای امضا کافی نیست. `generateProtectedKey` در این مرحله صرفاً با کلیدهای آزمون استفاده می‌شود؛ تولید کلید واقعی، تنظیم ACL و اجرای CLI مستلزم مجوز جداست. descriptor حداکثر دو کلید دارد: یک فعال و یک یدکی. `privateKey` فقط برای کلید فعال و `publicKey` برای هر دو پاسخ می‌دهد. کلید خصوصی، مسیر descriptor و محتوای آن نباید log شوند.

بستهٔ عمومیِ `buildV2TrustBundle` فقط شناسه و کلید عمومی دارد. انتشار/ابطال آن در build نسخهٔ دوم و تازه‌سازی تب‌های باز در برش جداگانه انجام می‌شود؛ این کد به‌تنهایی لغو کلید در مرورگرهای باز را تضمین نمی‌کند.
