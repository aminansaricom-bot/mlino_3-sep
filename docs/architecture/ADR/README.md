# مرجع ADRهای معماری MLINO

این پوشه نسخهٔ مرجع ADR-0001 تا ADR-0012 را در مسیر رسمی مستندات مخزن در اختیار پیاده‌سازی قرار می‌دهد.

## اصل نگهداری

- محتوای دوازده ADR از منبع موجود در Workspace بدون بازنویسی و بدون تغییر بایتی کپی شده است.
- وضعیت، تصمیم‌ها، تاریخچه و شمارهٔ ADRها تغییر داده نشده‌اند.
- این پوشه ADR جدیدی ایجاد نمی‌کند و جایگزین پروتکل `AI_HANDOFF` نیست.
- برای هر تغییر آینده در یک ADR باید فرایند رسمی تغییر معماری و بررسی مالک اجرا شود.
